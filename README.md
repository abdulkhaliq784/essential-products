# Essential Products

An online store for essential household products: cleaning towels, garbage bags and cooking oil. Prices are in INR.

Built with Next.js (App Router, TypeScript, Tailwind CSS), Supabase (Postgres, Auth, Row Level Security) and Razorpay.

See [SETUP.md](SETUP.md) for full setup, configuration and deployment instructions.

```bash
npm install
cp .env.example .env.local   # then fill in the values
npm run dev
```
